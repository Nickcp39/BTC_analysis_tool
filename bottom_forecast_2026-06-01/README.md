## 三、AHR999 怎么算的(算"底"尤其该用它)

AHR999 是经典抄底指标,定义 **AHR999 = P² / (gma200 × est)**(gma200=200日几何均价,est=币龄指数估值)。

- **底部 AHR999 极稳**:2018 底 = 0.279,2022 底 = 0.284 → 取 **0.28**(这是整套里最稳定的历史规律)。
- **est 可精确外推**:est 是币龄幂律函数 log10(est)=5.84·log10(age)−17.01,与价格路径无关 → 外推 **est@2026-10 ≈ $180,403**。
- **反推**:P = √(AHR999 × gma200 × est)。对 gma200 假设**不敏感**(√弱化):

| gma200@2026 | 反推底价 |
|-------------|----------|
| $70,000 | $59,621 |
| $80,000 | $63,738 |
| $90,000 | $67,604 |

→ AHR999 法给 **$60-67k**,与退火法、2 月低点高度吻合。**这是第二个完全独立于"波动退火"的确认。**

> ⚠️ 风险:底部 P/est 在下降(2018=0.536 → 2022=0.384),若继续降,底价会向 **$42k** 下移(偏向比值法的深熊)。所以 $63-66k 的前提是"相对估值不再大幅恶化"。
