## 3. 全局常量表

**这些参数经过研究验证，不要随意改动。**

### 3.1 时间锚点

| 周期 | 减半日 (halving) | 峰值日 (peak) | 来源 |
|------|-----------------|---------------|------|
| Cycle 1 (2013) | 2012-11-28 | 2013-12-04 | 历史确认 |
| Cycle 2 (2017) | 2016-07-09 | 2017-12-19 | 历史确认 |
| Cycle 3 (2021) | 2020-05-11 | 2021-auto 或 2021-11-10 | `idxmax("2021")` |
| Cycle 4 (2025) | 2024-04-20 | 2025-08-15 | **假设值** |

### 3.2 波动退火参数

| 参数 | 值 | 含义 |
|------|-----|------|
| `VOL_LEVEL_2013` | 27.0 | 2013 周期波动强度（仅 step04 使用） |
| `VOL_LEVEL_2017` | 9.0 | 2017 周期波动强度 |
| `VOL_LEVEL_2021` | 3.0 | 2021 周期波动强度 |
| `VOL_LEVEL_2025` | 1.0 | 2025 周期波动强度（参考基准） |
| `VOL_ALPHA` | 0.5 | 退火指数（平方根缩放） |

### 3.3 窗口参数

| 参数 | 值 | 含义 |
|------|-----|------|
| `POST_DAYS` | 60 | 峰值日之后继续取的天数 |
| `MAX_PRE_DAYS` | 300 | 峰值日之前最多回溯的天数（从减半日起算） |
| `PRE_STD_SPAN` | 90 | 计算峰前波动率的天数窗口 |

### 3.4 时间融合权重

| 模型 | 权重 | 含义 |
|------|------|------|
| 中位数模型 (base) | 1.0 | halving→peak 天数中位数 |
| 回归模型 (regression) | 1.3 | 减半间隔 vs halving→peak 线性回归 |
| 峰峰外推 (peak-to-peak) | 1.1 | 峰值间隔平均值外推 |

### 4.2 预处理流程

```
原始数据 (date, price)
     │
     ▼
① 日频对齐 (resample → daily, ffill)
     │  对于缺失交易日，用前一天收盘价填充
     │
     ▼
② 多源合并 (stepA3_pre_data_summary)
     │  优先级: FRED > btc_price_fred > btc_2021 > btc_2015
     │  去重: 同一日期保留最高优先级来源
     │  填充: 合并后仍缺失的日期，forward fill
     │
     ▼
③ 输出: btc_merged_daily.csv
     │  格式: date, price, source
     │  排序: 按日期升序
```

### 4.3 数据校验规则

```python
# 校验 1: 数据存在性
```

## 5. 模块 B：波动退火对齐（核心算法）

### 5.1 概念：为什么要退火

BTC 每轮周期的波动幅度在递减：
- 2017 周期：从减半到峰值涨了 ~30 倍
- 2021 周期：涨了 ~8 倍
- 2025 周期：预计涨幅更小

**如果直接叠加三条曲线，2017 的振幅会"吃掉"2025。**

退火的本质是：**按波动强度比例缩小历史曲线的振幅，使其与当前周期可比。**

### 5.2 窗口提取

```
定义:
  halving = 该周期的减半日
  peak    = 该周期的峰值日
  post_days = POST_DAYS (60)
  max_pre   = MAX_PRE_DAYS (300)

窗口起点 = max(halving, peak - max_pre)
窗口终点 = min(数据最后一天, peak + post_days)

提取: series[窗口起点 : 窗口终点]
```

### 5.3 相对锚点曲线（Percentage Curve）

```
输入: 日频价格序列 P(t), 锚点日期 anchor
输出: (rel_day, dd_pct) 序列

anchor_price = P(anchor)
  如果 anchor 不在序列中, 取 anchor 之前最近的交易日价格

对每个日期 t:
  rel_day(t) = (t - anchor).days
  dd_pct(t) = (P(t) / anchor_price - 1) × 100

示例:
  anchor = 2025-08-15, anchor_price = 100,000
  t = 2025-06-01, P(t) = 70,000
  rel_day = -75
  dd_pct = (70000/100000 - 1) × 100 = -30.0
```

### 5.4 峰前波动率（Pre-peak Volatility）

```
定义:
  span = PRE_STD_SPAN (90天)

pre_std = σ(dd_pct(t))  for t where rel_day ∈ [-span, 0]

其中 σ 是总体标准差 (ddof=0, numpy 默认)

具体:
  pre_values = [dd_pct(t) for t if -90 ≤ rel_day(t) ≤ 0]
  pre_std = sqrt(Σ(x - x̄)² / N)    # 注意: N, 不是 N-1
```

### 5.5 波动退火缩放（Volatility Annealing Scale Factor）

**方法 1: Manual（默认）**

```
scale_factor(source → target) = (VOL_LEVEL_target / VOL_LEVEL_source) ^ VOL_ALPHA

示例:
  2017 → 2025: (1.0 / 9.0) ^ 0.5 = 0.1111 ^ 0.5 ≈ 0.3333
  2021 → 2025: (1.0 / 3.0) ^ 0.5 = 0.3333 ^ 0.5 ≈ 0.5774

应用:
  dd_pct_scaled(t) = dd_pct_raw(t) × scale_factor
```

**方法 2: Std（实际波动率比）**

```
scale_factor = pre_std(target) / pre_std(source)

示例:
  pre_std_2017 = 45.2, pre_std_2025 = 15.1
  scale = 15.1 / 45.2 ≈ 0.334
```

**方法 3: Hybrid（方法 1 × 方法 2）**

```
scale_factor = manual_scale × std_scale
```

**当前默认: 方法 1 (manual)**

### 5.6 退火后对齐（Step01 核心输出）

```
对每个历史周期 i ∈ {2017, 2021}:

1. 提取窗口: window_i = series_i[halving_i → peak_i + POST_DAYS]
2. 计算曲线: (rel_day_i, dd_pct_i) = pct_curve(window_i, peak_i)
3. 计算退火: scale_i = (VOL_LEVEL_2025 / VOL_LEVEL_i) ^ 0.5
4. 应用退火: dd_pct_scaled_i = dd_pct_i × scale_i

对当前周期 2025:
1. 提取窗口: window_25 = series_25[halving_25 → latest_date]
   (不超过 peak_25 + POST_DAYS)
2. 计算曲线: (rel_day_25, dd_pct_25) = pct_curve(window_25, peak_25)
3. 不缩放: dd_pct_scaled_25 = dd_pct_25 (scale = 1.0)

输出:
  三条曲线在同一 rel_day 坐标系下:
  - dd_pct_2017_scaled (退火后)
  - dd_pct_2021_scaled (退火后)
  - dd_pct_2025 (原始)
```

### 5.7 匹配度指标

```
在退火后的曲线之间计算匹配度:

对 cycle_i vs cycle_2025, 取 rel_day 重叠区间:
  overlap = rel_day_i ∩ rel_day_25

分段计算:
  Pre-peak (rel_day ≤ 0):
    r_pre  = pearson_correlation(dd_pct_i[pre], dd_pct_25[pre])
    rmse_pre = sqrt(mean((dd_pct_i[pre] - dd_pct_25[pre])²))

  Post-peak (rel_day ≥ 0):
    r_post  = pearson_correlation(dd_pct_i[post], dd_pct_25[post])
    rmse_post = sqrt(mean((dd_pct_i[post] - dd_pct_25[post])²))

解读:
  r > 0.9 → 形态高度相似
  r > 0.7 → 形态较相似
  r < 0.5 → 形态偏离较大

  rmse < 5  → 偏离很小
  rmse < 15 → 偏离可接受
  rmse > 25 → 偏离较大
```

## 6. 模块 C：时间多模型融合

### 6.1 目的

峰值日期 (2025-08-15) 是假设值。用三个独立模型交叉验证，给出时间窗口。

### 6.2 模型 1：中位数模型 (Base)

```
计算每个历史周期的 halving → peak 天数:
  d_1 = (2013-12-04) - (2012-11-28) = 371 天
  d_2 = (2017-12-19) - (2016-07-09) = 528 天
  d_3 = (2021-11-10) - (2020-05-11) = 548 天  (若用 auto-detect)

中位数:
  d_median = median(d_1, d_2, d_3) = 528 天

预测:
  peak_model1 = halving_2024 + d_median
              = 2024-04-20 + 528 天
              = 2025-09-29
```

### 6.3 模型 2：回归模型 (Regression)

```
自变量 x: 减半间隔 (halving_i+1 - halving_i)
因变量 y: halving → peak 天数

数据点:
  x = [halving_interval_1→2, halving_interval_2→3]
  y = [d_2, d_3]

  其中:
    halving_interval_1→2 = (2016-07-09) - (2012-11-28) = 1319 天
    halving_interval_2→3 = (2020-05-11) - (2016-07-09) = 1402 天

线性回归: y = a × x + b
  使用 numpy.linalg.lstsq([[x1, 1], [x2, 1]], [y1, y2])

预测:
  x_new = halving_interval_3→4 = (2024-04-20) - (2020-05-11) = 1441 天
  d_regression = a × x_new + b
  peak_model2 = halving_2024 + d_regression
```

### 6.4 模型 3：峰峰外推 (Peak-to-Peak)

```
计算峰值间隔:
  interval_1 = (2017-12-19) - (2013-12-04) = 1476 天
  interval_2 = (2021-11-10) - (2017-12-19) = 1422 天

平均间隔:
  avg_interval = mean(1476, 1422) = 1449 天

预测:
  peak_model3 = peak_2021 + avg_interval
              = 2021-11-10 + 1449 天
              = 2025-10-24
```

### 6.5 加权融合

```
日期 → 序数 (ordinal):
  o_1 = peak_model1.toordinal()
  o_2 = peak_model2.toordinal()
  o_3 = peak_model3.toordinal()

权重:
  w = (1.0, 1.3, 1.1)

融合:
  o_fused = Σ(o_i × w_i) / Σ(w_i)
  peak_fused = date.fromordinal(round(o_fused))

时间窗口:
  window_start = min(peak_model1, peak_model2, peak_model3)
  window_end   = max(peak_model1, peak_model2, peak_model3)
  window_width = (window_end - window_start).days

解读:
  window_width < 30 天 → 模型高度一致
  window_width 30~90 天 → 正常不确定性
  window_width > 90 天 → 不确定性较大
```

## 7. 模块 B 扩展：时间缩放对齐

### 7.1 时间缩放因子（Step03/04/05）

```
概念: 不同周期的 halving→peak 天数不同，时间轴需要拉伸/压缩才能对齐。

计算:
  d_ref = (peak_2025 - halving_2024).days   # 参考周期天数 (如 482 天)
  d_i   = (peak_i - halving_i).days          # 历史周期天数

  time_scale_i = d_ref / d_i

示例:
  d_2017 = 528, d_2025 = 482
  time_scale_2017 = 482 / 528 = 0.913  (2017 略长, 需压缩)

  d_2021 = 548, d_2025 = 482
  time_scale_2021 = 482 / 548 = 0.880  (2021 更长, 压缩更多)

应用:
  rel_day_scaled_i = rel_day_i × time_scale_i
```

### 7.2 双重缩放（振幅 + 时间）

```
Step04/05 同时做振幅退火和时间缩放:

对历史周期 i:
  1. 振幅缩放: dd_pct_amp_scaled = dd_pct × amp_scale_i
  2. 时间缩放: rel_day_time_scaled = rel_day × time_scale_i
  3. 重采样: 用 numpy.interp 将缩放后曲线映射到参考周期的 x 轴

输出:
  (rel_day_ref, dd_pct_i_double_scaled)
  所有周期在同一个 x 轴上, 振幅也经过退火
```

### 7.3 时间收缩趋势（Step03）

```
Step03 分析周期持续时间是否在收缩:

Halving → Peak 天数:
  Cycle 1: 371 天
  Cycle 2: 528 天
  Cycle 3: 548 天
  → 趋势: 逐步延长 (但增速递减)

Peak → Next Halving 天数:
  Cycle 1→2: 919 天
  Cycle 2→3: 1249 天 (含第二峰)
  Cycle 3→4: 524 天
  → 趋势: 显著缩短

时间收缩比 (scale_to_ref):
  以某周期为参考, 其他周期需要拉伸/压缩多少
  scale = ref_days / cycle_days
```

## 8. 模块 D：峰后分析

### 8.1 纯峰后对比（StepB4）

```
仅提取 rel_day ≥ 0 的数据:

对每个周期:
  1. 切片: post_data = data[rel_day ≥ 0]
  2. 峰后波动率: post_std = σ(dd_pct[rel_day ≥ 0])
  3. 峰后天数: post_days_actual = max(rel_day) - 0
  4. 时间缩放到参考:
     N_ref = post_days_2025
     x_scaled = rel_day × (N_ref / post_days_i)

输出: 各周期峰后曲线在统一时间轴上的对比
```

### 8.2 峰前退火 + 峰后原始（StepA1_01_b4）

```
分段处理策略:

峰前 (rel_day ≤ 0):
  使用 Step01 的振幅退火
  dd_pct_left = dd_pct × (VOL_LEVEL_2025 / VOL_LEVEL_i) ^ 0.5

峰后 (rel_day > 0):
  使用原始振幅 (不退火)
  dd_pct_right = dd_pct_raw
  时间缩放: x_right = rel_day × (N_ref / post_days_i)

拼接:
  x轴 = [...负数(峰前), 0, ...正数(峰后)]
  y轴 = [...退火值(峰前), 0, ...原始值(峰后)]
```

### 8.3 峰后跳空处理（StepA2）

```
场景: 2025 周期中 peak(08-15) 到 post_start(10-03) 之间有数据空白

处理:
  峰前: halving_2024 → 2025-08-15 (正常)
  峰后: 从 2025-10-03 开始, 跳过 08-16 ~ 10-02

  参考价格不变: anchor_price = P(2025-08-15)
  dd_pct = (P(t) / anchor_price - 1) × 100

  重映射 x 轴:
    x_post = linspace(1, N_ref, len(post_data))
    (将 10-03 之后的数据等间距映射到 [1, N_ref])
```

## 9. 模块 E：扩展窗口与衰减建模

### 9.1 原始天数长窗口（StepA3_extended_200）

```
与 Step01 区别:
  - 峰后 x 轴使用原始天数 (不做时间缩放)
  - 窗口更长: WINDOW_DAYS = 400 天 (而非 60)
  - 峰后有独立的波动率缩放:

峰前:
  amp_scale = (VOL_LEVEL_2025 / VOL_LEVEL_i) ^ 0.5  (同 Step01)

峰后:
  post_scale = (pre_std_ref / pre_std_i) ^ POST_SCALE_ALPHA
  POST_SCALE_ALPHA = 1.0

  dd_pct_post_scaled = dd_pct_post × post_scale
```

### 9.2 峰后衰减系数（StepA3_post_scaled）

```
核心创新: 引入 POST_GAMMA 衰减

POST_GAMMA = 0.65

含义: 峰后的有效波动率 = 峰前波动率 × gamma

计算:
  pre_scale = (VOL_LEVEL_2025 / VOL_LEVEL_i) ^ 0.5
  post_scale = pre_scale × POST_GAMMA

效果:
  峰前: 曲线按 pre_scale 缩放
  峰后: 曲线按 pre_scale × 0.65 缩放 (振幅更小)

  直觉: 每轮周期峰后的下跌幅度, 相对于峰前的波动, 在递减
         (2017峰后跌了84%, 2021跌了77%, 2025可能跌更少)
```

## 10. 逆向推导：日期 → 价格区间

### 10.1 算法

```
输入: target_date (如 2026-04-01)
输出: (price_low, price_high, phase, explanation)

步骤:

1. 时间定位:
   days_from_peak = (target_date - peak_2025).days
   days_from_halving = (target_date - halving_2024).days

2. 阶段判断:
   IF days_from_peak < -30:
     phase = "pre_peak"
   ELIF -30 ≤ days_from_peak ≤ 0:
     phase = "near_peak"
   ELIF 0 < days_from_peak ≤ 60:
     phase = "early_decline"
   ELIF 60 < days_from_peak ≤ 450:  # ~1.2年
     phase = "post_peak_to_bottom"
   ELSE:
     phase = "post_bottom"

3. 价格插值:
   基于退火曲线, 在 target_date 对应的 rel_day 处:

   pre_peak:
     从历史退火曲线读取 dd_pct_2017(rel_day) 和 dd_pct_2021(rel_day)
     dd_pct_range = [min(dd_pct_2017, dd_pct_2021), max(...)]
     price_range = peak_price × (1 + dd_pct_range / 100)

   post_peak_to_bottom:
     progress = days_from_peak / total_decline_days  # 0→1
     peak_price_range = [120000, 160000]  # 假设
     bottom_price_range = [40000, 60000]  # 假设
     price_range = peak_range × (1 - progress) + bottom_range × progress
```

## 12. 数值验证基准

任何重新实现（API 化、前端移植等）都必须通过以下数值验证：

### 12.1 退火缩放因子验证

```
输入: VOL_LEVEL_2017=9, VOL_LEVEL_2025=1, alpha=0.5
期望: scale = (1/9)^0.5 = 0.33333...

输入: VOL_LEVEL_2021=3, VOL_LEVEL_2025=1, alpha=0.5
期望: scale = (1/3)^0.5 = 0.57735...
```

### 12.2 曲线值验证

```
使用 step01 输出的 halving_to_peak_aligned.csv 作为基准:
  取 rel_day = -100 处的 dd_pct_2017_scaled
  API 计算结果与基准差异 < 0.001%
```

### 12.3 时间模型验证

```
使用 step02 输出的 time_fusion.txt 作为基准:
  三个模型的预测日期完全一致 (精确到天)
  融合后日期完全一致
```

## 13. 参数敏感性说明

**哪些参数改了影响大，哪些改了影响小：**

| 参数 | 敏感度 | 改动影响 |
|------|--------|----------|
| 峰值日 (peak_2025) | **极高** | 改 1 天，所有曲线水平平移 1 天 |
| VOL_LEVEL_* | **高** | 直接改变退火系数，曲线振幅变化 |
| VOL_ALPHA | **高** | 改变退火强度，0.5→0.7 差异显著 |
| POST_DAYS | 低 | 只影响峰后窗口长度 |
| MAX_PRE_DAYS | 低 | 只影响峰前截断位置 |
| PRE_STD_SPAN | 中 | 影响波动率计算，间接影响 std 方法的退火系数 |
| 融合权重 | 中 | 影响融合峰值日期，但三模型差距不大时影响有限 |
| POST_GAMMA | 中 | 只影响 A3_post_scaled 的峰后振幅 |
