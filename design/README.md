## 推荐阅读顺序

### 第一层：搞懂方向（先读）

1. **[长期财富决策系统_产品定位与需求V1.md](./长期财富决策系统_产品定位与需求V1.md)**
   产品愿景。三层决策模型（市场/机会/个人），为什么先做 BTC。

2. **[00_系统总架构.md](./00_系统总架构.md)**
   三层架构 + 统一输出接口 + 交叉判定矩阵 + 文档地图。

### 第二层：搞懂逻辑（核心）

3. **[02_决策判定流程.md](./02_决策判定流程.md)**
   五关判定：数据校验 → 机会层 → 市场层 → 个人层 → 交叉判定。

4. **[03_核心算法规格书.md](./03_核心算法规格书.md)**
   ⭐ 公式级精度。12 个脚本的所有算法统一记录。拿到此文档可以不看代码完整复现。

### 第三层：搞懂实现（开发用）

5. **[01_机会层插件规范.md](./01_机会层插件规范.md)**
   插件目录结构、manifest、基类接口、BTC/NVDA 示例。

6. **[05_BTC周期插件详细设计.md](./05_BTC周期插件详细设计.md)**
   ⭐ 第一个插件的完整实现规格。12 个脚本→ 4 个模块的重组映射、周期阶段判定规则、风险等级计算、置信度公式、信号决策树、图表规格、测试策略。

7. **[04_数据流与状态机.md](./04_数据流与状态机.md)**
   5 级数据层级（L0-L4）、存储设计、触发机制、更新状态机、失败处理。

### 补充：外部验证

8. **[06_外部参考与设计验证.md](./06_外部参考与设计验证.md)**
   对比 GitHub 上 10+ 个类似项目（OpenBB、Ghostfolio、Qlib 等），验证架构决策，找出可借鉴的设计模式。

### 开发执行

9. **[07_开发计划.md](./07_开发计划.md)**
   ⭐ 5 个 Milestone 的完整开发计划。每阶段任务清单、时间估算、Done Criteria、风险应对。

### 第四层：产品与实施

10. **[市场层决策引擎_流程更新与IO定义V1.md](./市场层决策引擎_流程更新与IO定义V1.md)**
   市场层内部 6 层引擎（Raw Data → Facts → Scores → Policy → Recommendation → Explanation）。

9. **[BTC价格预测小程序设计.md](./BTC价格预测小程序设计.md)**
   前端产品设计稿。

10. **[实施计划_Phase1_后端API.md](./实施计划_Phase1_后端API.md)**
    FastAPI 后端实施计划。
