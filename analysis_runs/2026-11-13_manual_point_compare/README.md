# 人工点位比对（2026-11-13 起）

用户 2026-11-13 标了本轮三个点，又给了三对 2021 ↔ 2025 的配对。这里只**记录**用户的点、按点位画图、算每段的时间比和幅度比，不另外拟合（项目约定：用户对齐，Claude 记录）。数据截至 2026-11-12 收盘 $70,822（FRED）。

## 两本账（都可以直接改日期后重跑）

| 文件 | 内容 |
|---|---|
| `marked_points.csv` | 三轮各 5 个点：垂直下跌线 → 底 → 跳涨第一根线 → 第一个小高峰 → 回调低点。本轮的垂直下跌线 / 跳涨 / 小高峰是用户标的；2021 轮的垂直下跌线用用户给的配对（2022-11-12）；其余是同定义的候选，`source` 列写明来源 |
| `user_pairs.csv` | 2021 ↔ 2025 配对：用户给的三对 + 报告的顶、底 + 底后的跳涨、小高峰 |

## 脚本和输出

- `compare_marked_points.py` → `png/marked_points_by_cycle.png`（三轮各自的价格 + AHR，五条竖线）、`png/marked_points_aligned.png`（以本轮为时间轴，前两轮按点位分段对齐：原始涨跌 / 幅度对齐 / AHR 压缩）、`marked_points_table.csv`、`marked_points_numbers.txt`
- `user_pairs_2021_2025.py` → `png/user_pairs_2021_2025.png`（2021 轮按配对分段对齐到本轮；时间对照；AHR）、`user_pairs_table.csv`、`user_pairs_numbers.txt`

## 读到的东西（只是记录，不是结论）

1. **底后这一段和 2021 轮几乎同步**：底→跳涨 46 / 48 天，跳涨→第一个小高峰 49 / 43 天，底→小高峰 95 / 91 天。
2. **小高峰之后开始分叉**：2021 轮小高峰（2023-02-20）后 18 天就见回调低点（-18.6%，硅谷银行），之后 60 天内涨了 51%；本轮小高峰（10-03）后已经 40 天、-16.5%，还在跌。按配对分段，本轮今天对应 2021 轮的 2023-04-01，那时 2021 轮已经比小高峰高 14.6%。
3. **AHR999 的压缩不是各个高度都一样**：在用户的配对上，AHR 0.3–0.5 这一段两轮几乎一样（对2 0.500 / 0.510，跳涨 0.337 / 0.337），压缩主要发生在高处（对1 1.373 / 0.612，顶 3.80 / 1.27）。所以 ③ 图里整条线乘 0.57 只是近似，低位会被压得过头。
4. **2017 轮有两种数法**：按「底后先横盘、再第一次垂直拉升」选，跳涨是 2019-03-28；机械规则会选到底后马上那波 +28% 反弹（2018-12-15 → 12-20）。2017 轮的对应关系比 2021 轮弱，主要参照 2021 轮。
