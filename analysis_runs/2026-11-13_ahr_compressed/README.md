# AHR999 按周期压缩重读（2026-11-13）

用户的要求（11-09、11-13）：配对点位给时间；AHR999 不是「低于某个数就买」，它的数字每轮都在被压缩，要从这个角度重新看现在。数据截至 2026-11-12 收盘 $70,822（11-13 盘中约 $68.5k）。

脚本 `ahr_compressed.py` → `ahr_compressed_numbers.txt`（全部数字）、`ahr_compressed_ladder.csv`（压缩后的水位换成今天的价格）、`png/ahr_compressed.png`。配对来自 `analysis_runs/2026-11-13_manual_point_compare/user_pairs.csv`。

## 做法

- 离底距离统一用 **L = ln(AHR / 该轮底的 AHR)**。三轮底的 AHR 几乎不动（0.272 / 0.267 / 0.281），被压缩的是离底的距离。
- 压缩量从**时间配对点**上量：同一个时间点上，比较两轮的 L。拟合 5 个点（顶、对1、对2、跳涨、小高峰）得 **L本轮 = 0.67 × L2021^0.80**：高处压得多（L 2 → ×0.58），低处压得少（L 0.25 → ×0.89）。另给 ×0.57、×0.78 两个整体倍数做对照。

## 结果

1. **今天 AHR 0.374，L +0.29**。反推回 2021 轮的刻度约等于 AHR 0.376。2021 轮跳涨（2023-01）之后的一年里，AHR 最低是 0.390（2023-09-11）、硅谷银行那次是 0.436。所以按压缩读法，这次回调**已经比 2021 轮底后第一年里任何一次回调都深**。按 ×0.57 读，则正好等于硅谷银行那次。
2. **时间和水位对不上**：按配对，今天对应 2021 轮的 2023-04 初，那时 2021 轮在上涨段，在它那一段牛市里的位置约 70%；本轮今天只有约 31%。本轮离底的距离已经退回到跳涨（L +0.18）和小高峰（L +0.70）之间偏下，跳涨后的涨幅按 L 算回吐了约八成。
3. **换成今天的价格**（按今天的 200 日几何均线 $72,601、拟合估值 $184,495）：
    - 2021 轮三次回调低点按配对拟合压缩后：$74.3k（2023-03）、$77.8k（2023-06）、$71.7k（2023-09）。今天 $70.8k 已经在三个之下。
    - **底的 AHR 不压缩**：AHR 回到本轮底的 0.281 = 今天约 **$61.4k**，和 8 月更高的低点 $62.8k 很接近。这是「06-30 是底」的硬下沿。
4. **前两轮真底之后，AHR 有没有再回到底的水平**：2021 轮没有（跳涨前的 2022-12-28 最低 0.314）。2017 轮有一次：2020-03-12 新冠暴跌，AHR 0.241，低于底的 0.272，那时离底 15 个月，价格仍比底高 56%。

## 注意

- 拟合只有 5 个点，2017 轮没有用户配对（图 ② 里的 2017 轮是把同一个拟合用了两次，只作参照）。
- AHR 的「拟合估值」随时间上升，200 日均线也在变，所以同一个 AHR 对应的价格每天都在漂移；上面的价格是按 11-12 的均线算的。
- 这是参照，不是预测，也不是买卖信号。
