> **制作：Claude**（Claude Code，Opus 5.5），2026-11-13。用户要求「推倒重来，但逻辑不变」，并要求标明是 Claude 做的。
> 前身是 v19（`analysis_runs/2026-06-04_segment_experiments/segment_cycle_workbench_v19.*`），v19 原样保留。

## 怎么用

在项目根目录下：

```bash
python analysis_runs/2026-11-13_cycle_workbench_v20_claude/cycle_workbench_v20.py
python analysis_runs/2026-11-13_cycle_workbench_v20_claude/workbench_server_v20.py
```

第一行用最新数据重建页面，第二行启动本地服务。然后浏览器打开 http://127.0.0.1:8766/ 。v19 用 8765 端口，两个可以同时开。

- **拖线**：在图上按住一条线（参考周期以外），左右拖 = 平移，上下拖 = 高度。按住 Shift 左右拖，或打开「拖动 = 时间比例」（快捷键 T），改时间比例，以这条线的锚点为中心拉伸。
- **键盘**：← → 平移（加 Shift 一次 10 天），↑ ↓ 高度，[ ] 时间比例，数字 1–5 选周期，Ctrl+Z 撤销。
- **右侧**：数据（价格 / AHR999）、锚点（顶 / 底 / 减半）、参考周期、锚点前后天数和常用窗口按钮。每轮可以单独显示或隐藏、改锚点日期、用滑块或输入框精调。
- **保存样本**：存进本目录的 `cycle_workbench_v20_samples.json` / `.csv`，每存一次自动存一张图到 `snapshots/<样本 id>.png`。改写前的旧库备份在 `sample_backups/`。
- **v19 旧样本**：右下「v19 旧样本（6 月）」页签可以直接载入 6 月存的 11 个样本，只读。

## 逻辑（和 v19 一样）

- 每轮对齐到同一种锚点（顶、底或减半）。
- 横轴：该轮「锚点后天数 × 时间比例 + 平移」。
- 纵轴：该轮「ln(值 ÷ 锚点那天的值) × 高度比例」。值是价格或 AHR999。
- 参考周期原样不动，其他轮被变换后叠在它上面。
- RMSE 是在参考周期有数据的每一天上，两条线纵轴差的均方根，只作读数。**程序不自动拟合，参数都由人拖。**
- 核对：v19 的样本「2021→2025 顶 ±6 个月，高度 0.60 / 时间 1.01 / 平移 −13」，v19 记的 RMSE 是 0.0993，在 v20 里载入算出来是 0.099。

## v20 新增

1. **五轮同屏**：2011 / 2013 / 2017 / 2021 / 2025，参考周期可选，默认是本轮。
2. **在图上直接拖线**，可以撤销。
3. **价格 / AHR999 切换**。参数按「参考周期 + 锚点类型 + 数据」分开记，切过去不会互相覆盖。
4. **每轮的线只画到前后两轮同类锚点为止**。比如时间压缩后，2021 轮的线不会跑进 2025 轮的数据。
5. **点位标记**：手标高低点来自 `output/core_points/manual_points.csv`，实心是高点，空心是低点。白圈是用户确认过的点位和配对，来自 `analysis_runs/2026-11-13_manual_point_compare/`。
6. **纵轴刻度**：范围小时按相对锚点的百分比；范围大时（老周期、AHR）按锚点的倍数（×0.1、×0.01）。
7. 保存时连图一起存；样本里记着 `tool = cycle_workbench_v20 (made by Claude)`。

## 数据

- 2014-12-01 起用 FRED CBBTCUSD（`data/btc_merged_daily.csv`，末行常是 Yahoo 当天盘中点）。
- 更早用 CryptoCompare 全历史（`data/btc_price_daily.csv`，从 2010-07-17 开始）。
- 2014-02-06～02-25 这 20 天，CryptoCompare 跟的是正在崩盘的 Mt.Gox（例如 02-20 是 $112，其他交易所在 $600 附近），用前后两天之间的对数线性插值代替。2013 年顶部仍含 Mt.Gox 溢价。2011、2013 年的单日大涨大跌是真实行情，保持不动。
- AHR999 用项目里 `signals/indicators.compute_ahr999` 的公式。
- 锚点（页面里可以改）：

| 周期 | 减半 | 顶 | 底 |
|---|---|---|---|
| 2011 | 无 | 2011-06-08 | 2011-11-18 |
| 2013 | 2012-11-28 | 2013-11-30 | 2015-01-14 |
| 2017 | 2016-07-09 | 2017-12-16 | 2018-12-15 |
| 2021 | 2020-05-11 | 2021-11-08 | 2022-11-21 |
| 2025 | 2024-04-20 | 2025-08-12 | 2026-06-30 |

- 本轮的顶是 2025-08-12 真顶，不用 10-05。每次重建的数据范围和锚点价格写在 `cycle_workbench_v20_build.txt`。
