# 这次下跌放进五轮里看（2026-11-13）

用户问：周期已经好几轮、数据更多了，最近的大跌让人心慌，想看具体情况。这里把五轮「见底后第一年」里所有 ≥10% 的回撤都列出来，和本轮 10-04 以来这次比。

- 五个底：2011-11-21、2015-01-14（早期两轮，Bitstamp 日收盘）、2018-12-15、2022-11-21、2026-06-30（FRED）；早期两轮的底取给定日期 ±10 天内的最低收盘。
- 本轮用 FRED 到 2026-11-12 的收盘，加 11-13 盘中 $68,537（命令行参数）。
- 运行：`python post_bottom_pullbacks.py 68537`

输出：`pullbacks_numbers.txt`（全部数字）、`pullbacks_table.csv`、`png/pullbacks_depth_vs_days.png`、`png/post_bottom_underwater.png`。

## 读数

- 本轮：10-04 $86,424 → 11-13 盘中 $68,537，**-20.7%，40 天，还在进行**；价格仍比底高 17%。
- 成熟两轮（2017、2021）底后一年内的 7 次回撤：深度中位 -17.7%，时长中位 49 天；比这次更深的只有 1 次（2019-06-26 → 11-24 的 -46.5%，发生在价格已经涨了 3 倍之后）。
- 早期两轮（2011、2013）：9 次，深度中位 -23.6%，最深 -40.8%，有 6 次比这次深。
- **四轮里，见底后一年内没有一轮跌破过底。**
