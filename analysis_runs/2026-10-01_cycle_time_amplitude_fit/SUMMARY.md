**结论**

- **本轮（2021→2025）完全符合**：每个阶段的时间都缩短（0.85–0.97），每个阶段的幅度都退火（0.31–0.82）。
- **拉长到四轮**：幅度退火 12 个比例**全部 < 1**，是很硬的规律；时间加速**不是每段每轮都成立**——2013→2017 反而变慢（早期市场节奏更快），2017→2021 基本持平，真正的加速只发生在本轮。
- **时间上最规整的是「顶→顶」**：1,473 → 1,423 → 1,373 天，每轮正好少 50 天（等比 ×0.966、×0.965）。牛市、熊市单段的长短会互相补偿，但加起来的整轮在稳定缩短。
- **幅度上最规整的是「牛市对数涨幅」**：四轮按固定比例缩小，等比拟合很贴（对数 R² = 0.99，四轮残差 +4.2% / -6.1% / +0.1% / +2.0%）。

- **时间**：顶→顶天数 D(n) = 1,473 − 50·n（n = 0 为 2013→2017）。下一个 n = 3：**1,323 天 → 2025-08-12 + 1,323 = 2029-03-27**。
