## 和前两轮比

- **这次回撤的大小正常**：前两轮底后一年内都有多次 −13% ~ −20% 的回撤（2023 年：−18.6% / −17.7% / −20.0%；2019 年：−17.6% / −13.2%），两轮都没跌破底。本轮 −12.2%（进行中）。
- **反弹偏弱，但在退火框架里**：底后第 129 天，2017 轮 +73.8%、2021 轮 +77.9%，本轮 +29.5%。按「每轮对数涨幅 ×0.687」退火：2017 轮同期退火两次 ≈ +29.8%（几乎重合），2021 轮退火一次 ≈ +48.6%（$87.0k）。本轮现在落在两条退火线的下沿。
- **按顶对齐的 AHR**：2021 轮在顶后第 487 天（2023-03-10，硅谷银行那次回撤）AHR 也回到过 0.436，之后继续走高。本轮现在是顶后第 451 天、AHR 0.431。
- **历史基准率**：2015 年以来任意一天出发，60 天内再跌 15% 的比例是 35.8%；只看前两轮「底后 90–365 天」这一段，是 28.4%。跌破本轮底（需再跌 22.8%）：全样本 60 天内 20.2%，底后阶段 13.0%。前两轮底后第一年里一次都没破底。

## 结论

水位回到「偏便宜」（全历史约 21 分位，AHR 0.43），不是深底（0.28）。从形态看，这更像真底之后第一年里常见的那种 −15% ~ −20% 回撤，而不是熊市续跌；不过本轮的反弹力度只有退火框架的下沿。要盯的两条线：**$72.7k–$73.2k（200 日均线）** 和 **$62.8k（8 月更高的低点）**。跌破 $62.8k 才会动摇「06-30 是底」这个判断。

样本只有两三轮，以上是历史参照，不是预测。
